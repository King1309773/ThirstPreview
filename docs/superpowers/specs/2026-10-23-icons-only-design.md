# 1.1.4：仅水滴图标

用户明确纠正展示要求：“我只想保留水滴图标”。此前“统一显示数值”的解释不再适用。

- 物品提示只显示水滴图标，不显示补水点数、滴数计数、文字前缀或数字回退。Shift 只保留可选的饱和度和脱水概率详情。
- 恢复已有的 ItemTooltipEvent 图标行和 PostText 绘制，保留 1.1.2 的 RS 底部高度及文字列表快照修复。继续由容器原生绘制，不取消或替换其提示。
- 当前整合包 133 条规则均为正值 1～20 点，用原生整滴/半滴精确表达。零值显示灰色空滴；负值用红色灰阶轮廓，奇数最后半滴只绘制右半，与原生蓝色半滴方向一致。自定义绝对值超过 20 的规则按口渴条 20 点上限显示十滴，不附加数值。
- 如果换行或裁切使图标行无法完整容纳，跳过绘制，不画数字，不覆盖容器底部说明。完全绕过 Forge 提示事件的界面仍需另行适配。
- 手持 HUD、解析器、原有配置开关保持原义。升级至 1.1.4，备份 v涛.3 旧包并发布新的 GitHub 测试版。

验证：先在 1.1.3 实际客户端观察图标行断言失败；为无计数的图标布局和整数边界运行失败测试，再实现；运行完整构建、独立代码审查及 RS/Forge 实际绘制检查。
