# Thirst Preview 设计

用户已于 2026-10-18 选择“物品提示 + 手持口渴条预览”。目标为当前整合包的 Minecraft 1.12.2、Forge 14.23.5.2860、SimpleDifficulty 0.3.9，客户端安装即可。

## 行为

- 背包和 JEI 的物品说明显示每次食用/饮用补充的水分点数，以及对应水滴格数（2 点 = 1 格）。按 Shift 显示水分饱和度及已知脱水概率。
- 主手持有有效补水物品时，在坚定意志现有口渴条上半透明闪烁预览可补充的水分；主手无补水物品时检查副手。使用中的物品优先。恢复预览限制到 20 点上限。
- 使用 SimpleDifficulty 已加载的规则，保留 metadata、NBT、首条匹配顺序；兼容原生饮料、水瓶、水壶。检查水壶时复制物品，避免显示功能修改真实 NBT。
- 不修改食物属性、口渴逻辑、存档或其他模组。保持 AppleSkin 的提示与饥饿条显示。禁止隐藏界面、创造/旁观或关闭口渴系统时绘制预览。

## 实现

- `ThirstValueResolver` 负责按实际消费顺序读取坚定意志规则。
- `ThirstValues` 保存每次使用的补水点数、绝对饱和度和脱水概率。
- `PreviewMath` 负责水滴部分填充与 20 点上限计算。
- `ClientEvents` 通过 ItemTooltipEvent 添加文本；AIR Pre 的 LOWEST 优先级在坚定意志更新布局后记录口渴条位置，AIR Post 叠加预览。采用坚定意志自身纹理，兼容当前和经典显示。
- 入口限定客户端依赖；提供中英文语言文件和独立开关配置。无需额外网络协议。
