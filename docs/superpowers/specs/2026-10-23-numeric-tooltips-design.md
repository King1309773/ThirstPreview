# 1.1.3：统一数值提示

用户已明确选择“所有容器统一显示数值，更简洁稳定”。此决定取代 1.1.2 容器方案中“正常显示图标、异常回退数值”的展示策略。

- 所有遵循标准物品提示生成路径的界面使用同一条蓝色数值，例如 `3 点`；不显示“补水：”前缀。
- 在 ItemTooltipEvent 生成普通文字，交由容器负责换行、宽度和底部说明。不再注册物品提示的 PostText 图标绘制监听器。
- Shift 仅额外显示已有的饱和度和脱水概率；补水点数一直显示，不重复添加。
- 保留现有补水规则解析、手持口渴条预览和配置开关。旧图标工具类保留为未接线工具，以控制本次修改范围。
- 未使用标准物品提示文字的完全自绘界面、非物品的任务名称及流体条目不属于通用覆盖范围。

验证使用旧版实际客户端失败记录、新版 RS/Forge 八种绘制场景、既有自动测试及独立代码审查。实际绘制不等于完整终端网络或存档消费行为测试。构建后备份并升级 v涛.3 的已安装 JAR，发布新的 GitHub 1.1.3 测试版。
