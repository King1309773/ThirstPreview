# 补水预览 / Thirst Preview

独立客户端模组，与坚定意志 SimpleDifficulty 0.3.9 联动。1.1.0 为图标与横条适配测试版，不是温度 HUD 的更新包。

## 使用

- 鼠标移到背包或 JEI 的食物、饮料上，在物品提示框内部显示原生蓝色水滴。**2 点 = 1 个完整水滴，1 点 = 半滴**。苹果汁 8 点显示 4 滴。
- 按住 Shift，查看精确补水点数、水分饱和度和已知脱水概率。
- 超过 10 滴时显示单滴加“×滴数”；零值显示灰色空滴和 0；负值显示红色轮廓滴加负滴数。图标行无法安全放入提示框时回退数值文本。
- 手持补水物品时，口渴条上闪烁显示可恢复的部分，超过 20 点的部分不会画到条外。当前 7 点、补水 8 点仅预览 7→15；负补水显示红色损失区。正在使用的物品优先，其次主手，再其次副手。
- 水壶显示每口的补水量，空水壶不显示补水预览。
- 支持当前水滴纹理和坚定意志经典纹理。补水行位于提示框内部，避开 AppleSkin 的外部饥饿度面板。
- 支持已核验 GraveStone 1.0.0 横向水条：浅蓝色半透明回复段，负值红色；原生水滴路径和横条路径互斥。菜单、F1、创造/旁观及无有效口渴能力时不预览。

例如，当前整合包的苹果补水 1 点（半格），西瓜补水 3 点（1.5 格），牛奶补水 4 点（2 格）。

## 安装及卸载

环境：Minecraft 1.12.2、Forge 14.23.5.2860、SimpleDifficulty 0.3.9、Java 8。

完全退出游戏后，备份并移出 `mods/thirstpreview-1.0.0.jar`，放入新测试 JAR（`build/libs/thirstpreview-1.1.0.jar`，交付副本名称含 `icons-bars-test`），然后重启。不能同时保留两个版本；不要替换温度 HUD 或 SimpleDifficulty。客户端安装即可，服务端不需要此附属。

可保留原来的 `config/thirstpreview.cfg`。本次只生成本地测试包，没有自动替换任何实例中的已安装模组，也没有上传 GitHub。

卸载时移除该 JAR；配置文件可保留。本模组只读取补水规则、添加客户端显示。

第一次启动后生成 `config/thirstpreview.cfg`：

| 设置 | 默认 | 用途 |
|---|---|---|
| showTooltip | true | 背包和 JEI 中的补水说明 |
| showHud | true | 手持时的口渴条恢复预览 |
| showDetailsWithShift | true | 仅在按 Shift 时显示精确补水量、饱和度与脱水概率；false 表示一直显示详情 |

修改配置后重启游戏。

## 数据来源和适用范围

读取坚定意志已经加载的 `config/simpledifficulty/consumableThirst.json`，按它的 metadata、NBT 和首条匹配顺序解析。也支持坚定意志原生饮料、水壶和原版可饮用药水的默认值。

水分饱和度采用坚定意志的绝对点数。提示显示每次使用的名义数值，实际水分条受 20 点上限限制。

联机时，客户端与服务端应使用相同的坚定意志食物配置。任意第三方脚本直接修改口渴能力的额外效果，以及额外给水壶叠加 JSON 消费规则的玩法，未包含在本版预测范围内。

横条适配仅接受已核验的 `GraveStone-1.0.0.jar`，SHA-256：`5D0013C23B177281688D5FA191922C61F06FC60A1530FC700196F85109BBB354`。它没有公开几何事件，因此本附属以公开配置、Forge 事件及当帧高度增量保守确认位置；其他模组同时改动高度时可能跳过预览。不存在、不匹配或适配异常时仅跳过该横条，不影响物品提示或原生水滴路径。后续其他版本的横条不能保证支持。

## 源码与构建

源码位于本目录 `src`。使用 Java 8 设置 JAVA_HOME 后运行：

```powershell
.\gradlew.bat test build --console=plain
```

`libs/SimpleDifficulty-1.12.2-0.3.9.jar` 是构建期引用，不会打入成品。构建使用 ForgeGradle 自动重混淆，成品只包含本模组的类和语言资源。

验证其他实例的规则可加 `-PpackRules=<consumableThirst.json绝对路径>`；验证限定横条指纹可加 `-PgravestoneJar=<GraveStone-1.0.0.jar绝对路径>`。缺少可选指纹测试文件时该项会跳过，不能据此声称已经验证该目标。

源码压缩包不附带坚定意志本体。单独解压源码后，先创建 `libs` 文件夹，将整合包中的 `SimpleDifficulty-1.12.2-0.3.9.jar` 复制进去再构建。

## 游戏内验收

1. 重启后在模组列表中确认出现 Thirst Preview。
2. 在背包和 JEI 查看苹果汁（4 整滴）、苹果（半滴）、西瓜（1 整+半滴）、牛奶和纯净水；按 Shift 查看精确数值。对同时有食物/补水的物品检查 AppleSkin 共存。
3. GUI 缩放改为小/大，鼠标放到四边；查看长描述物品。图标不得越框，空间不足应回退补水数值。检查经典/当前两套水滴纹理。
4. 生存模式下当前水量 7 点手持苹果汁，应仅在横条新增区显示浅蓝脉冲；19 点时只到 20，20 点时不画回复。饮用后比较实际变化。支持的左侧/右侧水条都要检查。
5. 若有负补水或超过 20 点的规则，检查红色轮廓/损失区及单滴计数；不要为测试直接修改主存档规则，可使用备份测试实例。
6. 确认空水壶、木棍不显示预览；副手饮料可用，正在使用副手时优先。切换热键栏后不能残留旧段。
7. 水下、低口渴、调整分辨率/GUI 缩放后检查位置；F1、背包/菜单、创造和旁观模式不显示手持叠层。
8. 在备份测试实例切回 SD 原生水滴条，确认原生预览恢复、横条叠层不重复。关闭本模组两个显示开关验证分别生效。

自动化验证和构建的具体结果见 `VERIFICATION.md`。这些检查不替代在实际存档中食用/饮用的验收。
